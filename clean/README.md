# Clean Corpus Subset

Open-weight-only subset of the toke training corpus, published as part of
the D13=E transparency decision.

## What this is

A representative sample of 100--200 toke programs selected from the full
corpus, restricted to outputs generated exclusively by **open-weight
models**.  This subset is safe to redistribute without proprietary-model
license concerns.

## Included models

| Model | Type |
|-------|------|
| `deepseek-chat` | Open-weight (DeepSeek) |
| `mechanical-*` | Deterministic transforms (no model IP) |

Qwen and Llama outputs are also eligible but were not used in the
current corpus generation run.

## Excluded models

All proprietary / closed-weight model outputs are excluded:

- `claude-*` (Anthropic)
- `gpt-*` (OpenAI)
- `grok-*` (xAI)
- `gemini-*` (Google)

## Selection criteria

1. **Open-weight only** -- generated by a model whose weights are publicly
   available, or by a deterministic mechanical transform.
2. **Compiler-validated** -- every program compiles cleanly under `tkc`.
3. **Judge-accepted** -- quality score >= 0.3.
4. **Stratified sample** -- proportional coverage across all phases (A--D)
   and categories to be representative of the full corpus.

## Files

- `manifest.json` -- machine-readable list of selected entries with
  metadata (model, phase, task ID, score).
- `programs/` -- the actual corpus JSON files.

## Regeneration

To regenerate this subset from the full (private) corpus:

```bash
python scripts/extract_clean.py --corpus-dir corpus --output-dir clean --limit 200
```

## Verification

Verify file integrity against published hashes:

```bash
python scripts/compute_hashes.py --corpus-dir clean/programs --output clean_hashes.json
```

Compare `clean_hashes.json` against the published hash file.
