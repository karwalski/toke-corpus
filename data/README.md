# Data Directory

Processed datasets, training data, and pipeline outputs. All derived from the raw corpus in `../corpus/phase2_deduplicated/`.

## Canonical Files (active, do not archive)

| File | Size | Purpose |
|------|------|---------|
| `corpus_default.jsonl` | 149MB | Full corpus in default syntax (46,754 entries). Source of truth for all downstream pipeline stages. |
| `train.jsonl` | 108MB | Active training set — 18,890 chat-format rows (system/user/assistant). Generated by `scripts/prepare_training_data.py`. |
| `eval.jsonl` | 6MB | Active eval set — 994 rows, same format as train. |
| `benchmark_tasks.jsonl` | 911KB | Benchmark task definitions (holdout). |
| `data_mix.json` | 103B | Source weighting configuration for training data assembly. |
| `holdout_manifest.json` | 64B | Holdout set manifest. |
| `holdout_task_ids.txt` | 6KB | Task IDs excluded from training (benchmark holdout set). |
| `eval_descriptions.txt` | 148KB | Eval set task descriptions. |
| `DATA_QUALITY.md` | 3KB | Data quality documentation. |

## Archive Candidates (stale or regenerable)

These files live in `data/` but are **not canonical training inputs**. They are superseded, intermediate, or regenerable. Move to `data/archive/` when convenient.

| File | Size | Reason |
|------|------|--------|
| `corpus_error_triples.jsonl` | 3.8GB | **Superseded** by `error_triplets_instruct.jsonl`. Raw error-repair triplets before instruction formatting. |
| `corpus_mutations.jsonl` | 1.2GB | **Regenerable** pipeline output. Mutation-generated variants (variable rename, let-to-mut, type widening). |
| `corpus_complexity_dedup.jsonl` | 46MB | **Intermediate** pipeline artifact. Complexity tier labels consumed during `prepare_training_data.py`. |
| `phase2_syntax_audit.jsonl` | 94MB | **Audit output**, not a training input. Phase 2 syntax violation results. |
| `corpus_quality_scores.jsonl` | 54MB | **Regenerable** quality metrics. Composite scores consumed during data selection. |
| `differential_sweep_training.jsonl` | 1.4MB | **Small sample data** from differential testing. |
| `differential_sweep_sample.jsonl` | 414KB | **Small sample data** from differential testing. |
| `parallel_corpus.jsonl` | 30KB | **Tiny** (60 lines). Python-toke translation pairs. |
| `negative_examples.jsonl` | 30KB | **Tiny** (20 lines). Broken programs for contrastive training. |

> **Note:** Do not `mv` files larger than 100MB without verifying disk space and confirming no active pipeline references them. Use `git mv` to preserve history.
